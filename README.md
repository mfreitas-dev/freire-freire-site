# Freire & Freire Advocacia — Site Institucional

Site institucional desenvolvido para o escritório **Freire & Freire Advocacia**, localizado em Aracaju, Sergipe.

🌐 **Site:** https://freireefreire.adv.br/

## Objetivo do projeto

Criar uma presença digital profissional para apresentar o escritório, explicar suas áreas de atuação e oferecer caminhos claros para que visitantes solicitem atendimento ou agendem uma consultoria.

## Principais recursos

- Apresentação institucional do escritório.
- Conteúdo organizado sobre áreas de atuação jurídica.
- Seção de perguntas frequentes para orientar visitantes.
- Informações de contato e links para atendimento via WhatsApp.
- Formulário de contato integrado ao serviço Web3Forms.
- Campo de consentimento relacionado à privacidade no envio do formulário.
- Mapa incorporado para ajudar a localizar o escritório.
- Layout responsivo para dispositivos móveis e desktops.
- Metadados para SEO e compartilhamento em redes sociais.

## Tecnologias e serviços

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Web3Forms para processamento do formulário
- Google Maps incorporado

## Executar localmente

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou use o Live Server.

O site é construído com tecnologias front-end e não requer banco de dados para exibir as páginas. O envio do formulário depende do serviço externo Web3Forms e da configuração correspondente.
